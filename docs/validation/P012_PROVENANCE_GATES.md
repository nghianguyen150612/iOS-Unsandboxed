# P012 validation gates

`make provenance-test` exercises bounded canonical evidence, invalid schemas/encoding/digests, duplicates, truncation, identity mismatches, local declarations, test-only authenticated/protected assertions, unknown anchor, tampering, production mock isolation and address/undefined sanitizers where supported. `make launch-binding-test` covers borrowed descriptors, scope identity, a post-enrollment copy, renamed protected fixture, disabled policy, content mutation, pathname replacement, wrong descriptor, stale evidence, hard links, symlinks, FIFO, Mach-O errors and local CLI preview. P009/P010/P011 suites retain their broader parser, policy and installer fixtures. The test provider and its object are synthetic and do not represent Apple provenance or a complete catalog.

CI runs `make test` on Linux, and builds the Rust CLI and C17 code with the Apple ARM64 iOS 12.0 target on macOS. The existing package checks inspect architecture, dynamic dependencies, signing status, integrity and reproducibility. Cross-compilation does not demonstrate iOS execution. Device validation, installed Amethyst identity, live hooks, SSH launch path, kernel acceptance, sandbox outcome and exact-object launch remain NOT RUN/UNVERIFIED until independently tested on the reference device. No test executes the fixture binary or changes trust caches, code signatures, kernels or sandbox labels.
